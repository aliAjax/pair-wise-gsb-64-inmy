# 食品工厂HACCP控制计划与偏差处置平台

独立React前端工程，采用Fluent UI、Redux Toolkit、RTK Query、React Router、Vite和TypeScript。数据通过浏览器持久化，无需后端。

## 功能

- 生产批次、放行状态、监测点与隔离范围。
- HACCP流程图和控制矩阵编辑，记录关键限值、频率和纠偏措施。
- 偏差登记、原因与证据调查、返工/报废分支、复核退回和签字。
- 未关闭偏差阻止批次放行。
- 召回行动：按领料单回填旧数据原料批次（缺失标记待补链）；受理供应商通知（同一通知只受理一次）后从原料批次追到生产批次与成品去向，命中批次立即冻结放行与后续领用；去向未补齐的批次保持待核查；班长处置确认按召回版本做乐观并发控制，后提交者保留记录并提示范围变化；写入中断自动恢复未完成批次，凭请求号幂等重试不重复生成已确认结果；批次、偏差与审计统一展示同一召回版本。
- 完整版本化审计和JSON追溯包导出。

端口为`18464`。

```bash
npm install
npm run build
npm run dev
npm run verify   # 召回链路状态机验收（回填/冻结/并发/断点续写）
```
